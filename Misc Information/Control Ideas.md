# Control Ideas

Some of these are mentioned in the guide already,

## Control Consolidation
* Sight Change to 4 button hatch switch if you do not have another analog stick
* Gear Lever can reduced to 2 buttons to avoid the complexity of programming a gear shifter.
* Tuner Dial can reduced to 2 buttons to avoid the complexity of programming a rotary selector.
* Mapping all give toggles to one button/switch.
* Mapping Hatch, Ignition, Start to one button. In theory Eject could also be mapped to this.

## Ergonomics
* Moving Camera Zoom In/Out, Night Scope, and Line Color Change to Left Block. This puts all main camera all camera controls in one place, the Zoom in/out is usually done as a rocker trigger on the left stick
* Moving F.S.S., Main Weapon Control, Sub Weapon Control, Reload, and Chaff to right block. This puts all combat controls in one place.
* Mapping a joystick's throttle to acceleration similar to how it is configured in Mechwarrior. Forward Throttle (Forward Gear + Full Pressure Accelerator), Backward Throttle (Reverse Gear + Full Pressure Accelerator).
* Quick gear change. Setting a macro that changes the gear to specified value instead of needing to cycle

## Modifiers
* For those who only have 1 mouse or 1 joystick for weapon aim, creating a modifier that changes the axis so that it controls sight change instead
  * SteelBound has an option for moving the sight when the weapons are aimed near the corner.
* Mapping the scroll wheel so that it can alter rotation speed or aim sensitivity


## Pedal Alternatives
* Using any of the unused analog controls on custom joysticks/throttles
  * Z Twist axis (works well for Slide Step)
  * Forward Y Axis for Accelerator, Backward Y Axis for Break
  * Secondary analog triggers for any.
  * As mentioned before Slide-Step can be put to a button instead of an analog control.
