# Control Options


## Control Consolidation
- The Gear Lever and Tuner Dial can be reduced to the 2 buttons each to avoid the complexity of programming 2 rotary switchs or gear shifters.
- 
- Mapping all toggles to one button/switch.
- Mapping Hatch, Ignition, Start to one button.
- 

## Ergonomics
- Moving Camera Zoom In/Out, Night Scope, and Line Color Change to Left Block. This puts all main camera all camera controls in one place, the Zoom in/out is usually done as a rocker trigger on the left stick
- Moving F.S.S., Main Weapon Control, Sub Weapon Control, Reload, and Chaff to right block. This puts all combat controls in one place.
- Mapping a joystick's throttle to acceleration similar to how it is configured in Mechwarrior. Forward Throttle (Forward Gear + Full Pressure Accelerator), Backward Throttle (Reverse Gear + Full Pressure Accelerator).
